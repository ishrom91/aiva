# Brand Assets

This directory contains brand-related assets for the Aiva AI Bot.

## Files

- `avatar.png` - Bot avatar image displayed in Telegram
- `logo_appicon.png` - App icon for mobile applications
- `logo_mark_light.png` - Light version of the logo mark
- `logo_mark_dark.png` - Dark version of the logo mark

These assets should follow the brand guidelines and be used consistently across all platforms.
